# G1 Fire order and "Important" bucket (owner rulings)

- Fire order, debts first (FT-R-82): when an older setup had a Fire savings goal, the move to the new model used to put that goal at the top of the
  Fire list, ahead of the debts. It now goes right after the last debt, before Mojo, Home and Super. With no debts it is still first.
  Changed in `src/state/bucket-migration.js`; the E4 note, the migration, Fire list and Today tests were updated to the new order, and one test added for the no-debts case.
- Everyday bucket names: a bucket called "Important", "Everyday", "Every day" or "Day to day" (also "Day-to-day") now counts as the daily-spending
  bucket, like "Daily". Whole words only, and only the first bucket that matches gets the role. `ROLE_MATCHERS` in `src/calc/saving-model.js`; new `detectRole` tests.

# A1 theme generator, tokens, palettes, fonts

- `scripts/build-themes.mjs` (run `npm run build:themes`, `--check` for drift) reads
  `src/theme/themes.json` (copy of the theme sheet) and writes `src/styles/tokens.generated.css`:
  4 palettes x light and dark = 8 token sets. Light is `html[data-palette=X]` (Sunrise also on `:root`),
  forced dark is `[data-mode="dark"]`, auto follows `@media (prefers-color-scheme: dark)` with
  `:not([data-mode="light"])`. Slots `--b1` to `--b10` (`-bg/-ink/-chart/-shade1..3`), role aliases
  (`--daily/splurge/smile/fire/mojo/grow-*`, var() references to slots 1 to 6), the seven derived
  tokens, and `.k1`-`.k10`, `.kN-s1`-`.s3`, `.p-bar.kN` (Mojo is slot 5). The forced Light and Dark
  blocks of the mock (`styles.css:638-880`) were not used.
- `src/styles/legacy-aliases.css` maps the old token names onto the new tokens; `src/styles/fonts.css`
  holds the Manrope `@font-face` (400 to 700, swap). Neither is linked into the app (A3/A4 wire them).
- `src/theme/palettes.js`: pure ids, labels, `resolvePalette`, `migrateAppearance` (never mutates, no keys
  renamed). Dark old presets (midnight, retrowave, forest, ocean, ume, copper, terminal, organs and the
  `default`/`dark` aliases) map to dark; light ones to auto.
- Contrast: 496 pairs (62 x 8), 0 failures (also asserted in the generator run).
- Font (G2): no fonttools/brotli on the machine. Ran once, dev-only, nothing saved to package.json:
  `npm install --no-save wawoff2@2.0.1` (MIT, fontello, Google woff2 compiled to wasm) then
  `node -e "require('wawoff2').compress(fs.readFileSync(ttf))"` writing `public/fonts/Manrope-Variable.woff2`.
  164,700 bytes TTF to 53,652 bytes woff2. Weights 400/500/700 verified distinct in the browser.
- Tests A1.1 to A1.5 in `palettes.test-cases.js`: node runner 60 passed; `tests.html` 246 (194 baseline + 52).

The `<link href="style.css">` was removed from `index.html` so the order is deterministic; built CSS verified in that order. FOUC inline script untouched. Note: legacy `style.css :root` hex fallbacks still override `legacy-aliases.css` until A4; at runtime `applyTheme` sets them inline, as before.

# D1 sheet, undo toast and dialog primitives

- New `openSheet` (src/ui/sheet.js, sheet.css): one declarative edit form, bottom sheet below
  768 px and a right-hand panel above; `role="dialog" aria-modal`, Escape and backdrop close,
  focus trap and restore, a single scroll area. `validate` blocks Save and puts the last good
  value back; `plausibility` shows a quiet note with a one-tap fix and never blocks.
  Pure helpers: `weeklyAmountRule`, `hoursRule`, `bucketTotalRule`, `createSheetModel`,
  `removeAt`, `deleteWithUndo`.
- `showUndoToast` in toast.js; toasts now go through one queue: a second toast replaces the
  first and commits it (`onExpire` once), timers pause on hover and focus, and duration 0 gives a
  persistent toast with a Dismiss button (storage full). `showToast` and the milestone listener
  are unchanged.
- `confirmDialog` (a modal `<dialog>`, resolves true or false); `showCustomModal` is now a thin
  wrapper over `showToast`. `confirmAction` and `inlineConfirm` stay until D2 and A12b.
- `src/ui/focus.js` holds the focus helpers; `modals.js` keeps its exports and uses them.
- Strings in `src/i18n/en-d.js` (`d.` keys). `sheet.css` imported from `main.js`.
- Test group `sheet` (D1.1 to D1.5) now runs in the Node runner (66 assertions); the DOM-only
  cases in D1.5 also run in tests.html. Demo page (not shipped): `docs/demo/d1-demo.html`.

# U1 - wider Plan and Settings column on desktop (conformance 3.12 / 3.13)

What changed
- `src/ui/plan.css`: from 1024 px up, `.p-body, .p-slot, .p-review` use `max-width: clamp(760px, 72vw, 1040px)` (was a flat 760 px).
- `src/ui/settings.css`: from 1024 px up, `.s-wrap` uses `max-width: clamp(720px, 72vw, 1040px)` (was 720 px).
- Widths: 1104 gives 795 px, 1280 about 921, 1440 gives 1037, 1920 gives 1040. Below 1024 the old rules apply untouched, so phone and tablet do not change (390 px figures identical).

Why: the owner chose option (a), widen to about two-thirds of the main area. No two-column layout, no totals beside cards.

Checked at 1104, 1440, 1920, light and dark: rows, right-aligned figures, review card, spending caps bars, categories list, Settings rows and theme swatches all hold up; no component needed its own max-width.

Tests: none added (CSS only); no test or sweep check tied to the old width existed. run-cases 2887/0, tests.html 3347/3347.

Left for later: the section 7 buckets block (`plan-buckets.css`) is not capped by these rules and stays full canvas width (1136 px at 1440), a little wider than the 1037 px lists above it.

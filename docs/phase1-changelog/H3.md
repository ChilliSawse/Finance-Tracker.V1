# H3 - iPhone header under the status bar; Future chart labels collide

Live bug fix (M-11), two layout bugs seen on the installed iPhone PWA.

- Header: the phone top bar (`.topbar`, base.css) was a fixed 56px with no top padding, while the page runs with
  `viewport-fit=cover` + `black-translucent`, so the status bar drew over the logo and the settings icon. It now pads and
  grows by `env(safe-area-inset-top, 0px)`. The inset is 0 in a normal browser tab, so nothing changes there. Still sticky.
- Future "Net worth path": the FI marker label ("FI: About N years") sat on the same row as the dashed line's own label
  ("FI - $981.6k") and overlapped it. The marker label now sits one full row higher (future.css). The x axis drops a tick
  that would touch the "N yrs" label (30-year view loses "25"; model.js `MIN_LAST_TICK_GAP_PCT`).
- Tests: H3.1 (tick gaps at 10/20/30 yrs), H3.2 (marker label row), H3.3 (top bar safe-area rule). 2990 -> 3002 cases.
- UNVERIFIED: real iOS status bar behaviour (Chromium only, inset emulated at 47px by rewriting env()).

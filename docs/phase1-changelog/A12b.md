## Added (so no duty is lost)
Deleting the Income modal removed the only editor for three things, so they get small sheets (new `src/ui/income-other.js`, strings `a12b.*` in `en-d.js`):
- Self-employed and Variable sources (C6's sheets cover Salary and Set-hours only): name, kind, how often, take-home, tax set aside, hours (Self-employed) or base hourly rate (Variable), "main income", and for Variable the income events (add, edit, delete with Undo). `plan.js` and the setup wizard's pay step now open it instead of clicking the removed `#open-income-settings`. It also carries "Open income statement".
- Delete a source from its sheet (all three sheets): Undo toast, and the last source is refused with a toast. This is the guard that kept a sheet: `canRemoveIncomeSource`.
- Settings, Region and tax: a "Tax details" row opens a sheet for the Medicare levy, HELP in the estimate and the HELP balance (the only editor of `taxSettings.helpBalance`, which Future's HELP card and the FI calculation read).

# B4 plan state API with undo payloads

- New `src/state/plan.js`: `addPlanItem`, `updatePlanItem`, `removePlanItem`, `convertToBill` (all `(data, ...)`, mutate `data.plan` in place),
  plus `newPlanItemId`. Each returns `{ok, item, index, message, onUndo, onExpire}`, so the result goes straight into `showUndoToast`.
  Callers render and save after the call and again after `onUndo`.
- New items count in totals (`inTotals` true, FT-R-53), bills included. `convertToBill` needs an `anchorDue`, optionally a frequency,
  and leaves `inTotals` alone (a migrated reminder stays a reminder, a counted line is not double counted).
- Undo is exact: add removes by id, edit restores a snapshot, remove reinserts at the old index (once only).
- `settings-events.js`: `plan` and `rules` added to `SETTINGS_COLLECTIONS`.
- Tests B4.1 to B4.3 in `plan.test-cases.js` (26 assertions); `run-cases` 800 to 826.
- Toast messages come from `src/i18n/en-b.js` (`b.plan.*`) via `t()`.

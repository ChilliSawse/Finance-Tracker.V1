# T2 Mojo tile double percentage

- Root cause: `getBuckets` (`src/state/saving-model.js:146`) put `mojoSteps().progressPct` (already 0 to 100) into `target.progress`,
  which every other target (Fire status) holds as a 0 to 1 fraction. `tileHtml` (`src/ui/today.js:331,340`) multiplies `progress` by 100,
  so A$1,400 of the A$2,000 starter read "starter · 7000% paid".
- Fix: `target.progress` for Mojo is now a fraction, `min(1, progressPct / 100)`, the same unit as Fire. The Plan Mojo ladder reads
  `progressPct` directly and was already right; Today and Plan now agree (70%).
- Test: `today.test-cases.js` "T2 Mojo tile reads the percent once" (70% at A$1,400 of A$2,000, no "7000", never over 100% when over target).
  `run-cases` 1496 to 1500; `tests.html` 1842 to 1846.

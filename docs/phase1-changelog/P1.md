# P1 - polish fixes (wave 13)

## What changed
- Today: the screen-reader data table now sits in a `div.today-sr` wrapper (1px, clipped, `clip-path`, anchored at 0,0); the table itself is `.today-sr-table`. A bare absolutely placed table kept its content width (361 px) and widened the page at 360/390. `tools/sweep.mjs` is now clean at all widths (it also reported the 360 bottom-nav overflow, which was this same widening).
- Header: under 480 px the save-status label shows only its dot (`font-size: 0`, text stays in the DOM and `aria-live`); `autosave.js` also sets `title` to the status text. No overlap with the theme button at 360.
- Quick-add: saving buckets no longer say "A$0.00 left". They show "{amount} saved" (new key `a.quickAdd.inBucket`) from the bucket balance, or nothing when the balance is zero. Spending buckets keep "{amount} left".
- `.sheet-note[hidden]` workaround removed from `income-layout.css` (E7 fixed it in `sheet.css`). `.sheet-error[hidden]` went with it; `.sheet-error` sets no display, so the attribute works natively. Visual unchanged (sweep screens identical).
- Transfers (Plan card and monthly review): a bucket with no `bankSetTo` entry and a 0 amount now shows "New" in the amount cell instead of A$0.00; review sub-line reads "New. Set this up in your bank" (`e.review.transferNew` reworded, new tags `e.plan.xferNewTag`, `e.review.transferNewTag`). A new bucket with a real share still shows its amount.

# S2 CSP hardening and HTML sinks (security review H2, sink side of M1)

- **CSP (H2).** The public nonce `ft-fouc-init` is gone. `script-src 'self' 'sha256-...'` allows the one inline FOUC script by hash. No `nonce-` and no `'unsafe-inline'` in `script-src`. Added `connect-src 'self'` (the app makes no network calls), `object-src 'none'`, `base-uri 'none'`, `form-action 'none'`, `frame-src 'none'`. Kept `worker-src 'self' blob:` (PDF.js), `style-src 'self' 'unsafe-inline'` (inline `style=` attributes are used widely), `font-src 'self' data:`.
- **Hash production.** `vite.config.js` has a small plugin, `ftCspHash` (`transformIndexHtml`, order post, so it runs in dev and in build). It finds the single classic inline script in `index.html`, hashes it as the browser will see it (CRLF normalised to LF), and rewrites the `sha256-` source in the CSP meta. It throws if there is not exactly one inline script. The committed hash in `index.html` is a fallback for raw hosting; test A4.3 checks it equals the SHA-256 of the exact script, so it cannot go stale. The FOUC script itself is unchanged (273 bytes), so the theme boot order is untouched.
- **Limits of a meta CSP.** `frame-ancestors`, `report-uri` and `sandbox` are ignored in a `<meta>` CSP, so clickjacking protection needs a real header (not available on GitHub Pages). `frame-src` is not applied to `about:srcdoc` frames: an injected `srcdoc` iframe can still render, but its scripts are blocked (the document inherits the policy). The real barrier there is the escaping below.
- **Sinks (M1).** New `src/ui/html.js` with `esc` (alias of `escapeHtml`) and `escNum` (a finite number prints as itself, null or empty as an empty string, anything else as an empty string). Numeric `value="${...}"` attributes and numeric text interpolations now go through `escNum`. `utils.js` is not edited.
  - `settings-forms.js` 21, `whatif.js` 14, `render-tabs.js` 4, `feed.js` 3 (event-log `count`, `threshold`, `value`), `income-statement.js` 6, `income-insights.js` 2. Total 50.
  - Already escaped and left alone: all name, date, label and text interpolations (they use `escapeHtml`). Remaining unescaped interpolations are constants or values derived by arithmetic or `toFixed` (not data strings).
  - Not touched (outside S2's files): `src/import/import-ui.js` and `src/import/pdf-ui.js` (S3 area; the review found their text sinks escaped). `formatCurrency` output is S1's fix in `utils.js`.
- **Tests.** New pure group `html` (`src/ui/html.test-cases.js`, S2.1 to S2.5, 29 assertions). A4.3 in `theme.test-cases.js` now checks the hash, the missing nonce and the four `'none'` directives instead of the old nonce.
- **Built-app checks** (standalone Playwright, own port, synthetic data only): no CSP console violations or `securitypolicyviolation` events across load, all four tabs, every settings modal, theme and mode switches, a PDF import and a reload. The FOUC script sets the cached palette and mode while `readyState` is `loading`, with no other palette afterwards. An injected inline script, one carrying the old nonce, and a `srcdoc` iframe script are all blocked.

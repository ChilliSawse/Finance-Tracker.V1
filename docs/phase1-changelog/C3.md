# C3 annual tax owed, LITO, refund or bill

- New `src/calc/tax-owed.js` (pure): `annualOwed({taxableIncome, date, hasStudyDebt, repaymentIncome})` (brackets minus LITO, Medicare, HELP; each rounded to cents), `litoFor`, `refundOrBill` (withheld per pay x cycles minus owed; kind refund/bill/even; always `estimate: true`, label "Estimated ..."), `annualEstimateForSources` (per-source `hasStudyDebt`; HELP on total repayment income, FT-R-75 D10).
- Table year is picked by date (FT-R-66/86). The saved `taxBrackets` copy and any stored year are never read (FT-R-97); extra input fields are ignored, so the A$627 stale-brackets mix cannot occur.
- LITO was already dated table data in each C1 year file (`lito`); reused, not duplicated. No change to `tax-au.js` or the tables.
- Tests: 6 cases (37 assertions) in `tax-owed.test-cases.js`: C3.1 refund 45.03, C3.2 refund 68.23, C3.3 refund 48.02 (and a bill case), C3.4 stale brackets have no effect, LITO bands, multi-source HELP.
- Estimate limits: single resident, no MLS, no offsets beyond LITO; a year can hold 27 pays.

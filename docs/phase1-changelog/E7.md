# E7 bucket sheets and the category bucket field

- `src/ui/bucket-sheets.js` fills `openBucketSheet(kind, id)`. Kinds: `split`, `template`, `goal` (E6's four, so E6's buttons now get the real sheets with no change to `plan-buckets.js`), plus `bucket` (id), `bucket-new`, `bucket-delete` (id), `goal-new` (id = parent, Smile when null), `target-pot`, `target-debt`. Returns false in Node or for an unknown kind or id.
- Edit split: a percent per bucket (Mojo and Grow are not edited), the engine's suggestion as each field's hint. At 98 `validate` refuses and Save is disabled (re-checked on typing and on the one-tap fix); the note offers "Put the difference into Smile". Pure: `bucketSplitSpec`, `splitValidate`, `splitPlausibility`, `splitSaveOk`.
- Delete: a bucket holding money, a share or the tax-pot tag always opens "Move A$x to..." with a required pick (no default, Mojo not offered); the tag moves with the money, one undo restores both. An empty bucket asks a plain confirm. A core bucket under the template offers the fork. `deletePlan`, `deleteBucketMoving`.
- Tax pot: `setTaxPot`; a held tag asks "Move the tag?" before anything is written (`code:'holds'`), `{move:true}` moves it. Bucket edit (rename via E5, bank note, spend or save pot for non-core buckets, tax tick) is `applyBucketEdit`, one undo.
- Goal sheet: the live calculator readout (from `smilePlan`) sits under the date field and updates as you type (`goalReadout`, `goalSheetSpec`). Delete goal and share field for existing goals. Mojo sheet: starter, months, basis, optional own step. Template sheet: name and "Make it mine"; on your own template, Switch back through a confirm.
- `categoryBucketField(category, buckets)` (for A9b): a D1 select field `{key:'bucketId', options, hint, value}`; first option "Follows essential tick" (value ''), then each top-level spend or save bucket. Save with `relinkCategory(d, id, bucketIdFromField(v.bucketId))`.
- Writes refresh through `updateDataAndUI` and a `ledger:buckets-changed` document event.
- `sheet.css`: `.sheet-note[hidden] { display: none; }` fixes empty notes showing. C6's workaround in `income-layout.css` can go later (not edited here).
- Strings `e.sheet.*` in `en-e.js`. Tests: group `bucket-sheets` E7.1 to E7.8 (41 assertions); `run-cases` 1537 passed, 17 skipped; `tests.html` 1883/1883 with the tripwire.
- Found, not mine: D1 `sheet.js` `setNote` (~line 360) rebuilds the fix button on every `change`, so a real mouse click on "Put the difference into Smile" after typing is lost (blur fires change, the button is replaced before mouseup). Keyboard and programmatic clicks work. D1 owner should keep the note node when its text is unchanged.
- Shape note: `splitSheetSpec` in E6's file keeps its name; E7's is `bucketSplitSpec` (the gate rejects duplicate export names).

# U2 Tax card in any month

Owner decision: the Today tax card shows in any month until the user checks a payslip for the current tax year or dismisses the card for that year.

- `taxTablesStatus` (`src/calc/tax-tables/index.js`): the July-to-September limit for a payslip-job source with no check yet is gone (`inFirstQuarter` removed). The Settings "Tax tables" row uses the same status, so it follows the same rule. New pure helper `pastFirstQuarter(now)`.
- `taxCardModel` (`tax-card.js`): from October to June the model carries `late: true`; the heading is the new string `c.tax.late.title` ("Check your take-home for {fy}", `en-c.js`). July to September keep "New tax year: {fy}".
- Dismiss already existed (C8): `dismissTaxCheck` writes `taxCheck = {fy, done:false, dismissed:true}`, per tax year, so a new year brings the card back. No change needed; `today.js` and `income-layout.js` untouched.
- Behaviour note: on 30 June a never-checked payslip-job user is now due for the year that is ending (2025-26), with the later heading. E10.10 updated for this and for October.
- Tests: U2.1, U2.2 (tax-card group), two assertions in C1.2b; E10.10 changed (October, 30 June). All dates pinned. run-cases 2887 to 2908.

# E9 Monthly review

- New `src/ui/review.js` and `review.css`: a Plan sub-screen built from existing cards, tiles and bars, in the four E3 blocks. Spending (essentials and non-essentials against plan, share of take-home, five biggest categories), bucket movements (a "Planned" tag and note when auto-credit is off, otherwise credited with start and end balances), target progress (Fire active target, Mojo ladder, Smile goals) and transfers to update. A month picker covers the last twelve complete months. Pure builders `reviewModel` / `reviewHtml`; wiring `mountReview` (Plan) and `mountReviewCard` (Today).
- Opening a month sets `savingModel.review.lastOpenedMonth` (forward only) and saves. On Today, `#today-review-slot` shows "<Month> review is ready" while `reviewDue` gives a month (from the 1st until opened); the button goes to Plan and opens it.
- Hooks outside the file: `plan.js` (import and one `mountReview()` call), `today.js` (import and one `mountReviewCard()` call), `main.js` (one css import), strings `e.review.*` in `en-e.js`.
- Mismatches found (E3's `review.js` left alone, this file reads the real paths): (1) the marker lives at `savingModel.review.lastOpenedMonth` (`bucket-migration.js:105`) but `reviewDue` reads `data.review` (`calc/review.js` reviewDue); `reviewDueFor` hands it the right view. (2) bankSetTo lives at `savingModel.transfers.bankSetTo` (`bucket-migration.js:102`, E5 `tickTransfer`) but `buildMonthlyReview` reads `savingModel.bankSetTo` (`calc/review.js:149`), so its `transfers` is always empty; `reviewModel` recomputes it. Suggest fixing both in `calc/review.js`.
- Sample household (21 Nov, October review): spending A$4,731.82 (essentials 4,126.40 under plan by 362.93; non-essentials 605.42 under by 188.91); movements empty (auto-credit on, no pay roll has run in the sample); targets Fire Credit card 0%, Mojo step A$2,000 at 70%, Bali trip saved up; transfers list four rows "was A$0.00" because the sample seeds `bankSetTo` at 0 (`bucket-migration.js` seedBankSetTo with net 0).
- Tests: group `review` (E9.1 to E9.5, 21 assertions). `run-cases` 1684 to 1705.

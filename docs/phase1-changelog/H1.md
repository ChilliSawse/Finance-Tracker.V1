# H1 Today shows nothing for a Self-employed source with no pay day (live bug fix)

Reported on iPhone after 2.0.0: Today showed only "Set your pay day" and "Add your pay to see what is left", although the pay amount was entered.

## Root cause

1. The migrated income source (Self-employed) has no pay date. With no pay date Today runs in month mode, where "left" is built from pay that has actually landed this month. With no transactions that is nil, so the empty card showed, and it asked for pay that was already entered. (Plan uses the planned pay, so it looked fine.)
2. The prompt could not be answered. "Set your pay day" opened the Salary sheet, which only exists for Salary and Set-hours sources. For Self-employed it returned false and the button just jumped to Plan. The Self-employed sheet had no pay day field at all, so a Self-employed user could never set one.

Not a service-worker or lazy-chunk issue; no console errors from Today.

## Changes

- `src/ui/income-other.js`: the Self-employed sheet gets a "Next pay day" field (same field, hint and anchor rule as the Salary sheet; blank leaves a saved date alone). `otherIncomeValues` reads it back.
- `src/ui/today.js`: when a pay amount exists but month mode shows nil, the empty card now reads "Set your pay day to see what is left" with the pay-day button (the separate nudge card is hidden then, so the button is not repeated). The button falls back to the Self-employed/Variable sheet, as Plan does, instead of jumping to Plan. With no pay amount at all the old "Add your pay" card stays.
- `src/i18n/en-a.js`: two new strings.
- Tests: `today` (new H1 case), `income-other` (field list updated, new H1 round trip).

## Open design call (not built)

Month mode still shows nothing until pay lands or a pay day is set. Showing the planned pay as "left" with only the countdown waiting on the date would be a design change.

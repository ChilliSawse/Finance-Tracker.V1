# M0 migration chain, contract stubs, test and gate scaffolding

- One migration chain, `runMigrationChain`, now runs the four legacy migrations and
  then four Phase 1 steps (plan, bucket, income fields, asset and debt detail), with
  the byte-exact backup key `ft-backup-pre-plan`, one forced save, and import-only
  `afterImport` hooks. The four Phase 1 steps are stubs that change nothing, so saves
  load, save and show exactly as before.
- Each Phase 1 step is atomic (runs on a clone, committed only on success) and the first
  failure stops the chain with no forced save, so a broken step never leaves half-migrated data.
- `loadData` and the JSON import call the chain instead of the four migrations directly.
- Stub modules with the final signatures for the cross-slice contract, listed in
  `docs/PHASE1-CONTRACT.md`.
- 30 registered test groups (`src/test-registry.js`) run by `tests.html` and by
  `node tools/run-cases.mjs`; eight new chain cases (M0.1 to M0.8). `tests.html` goes from
  186 to 194 assertions.
- `tools/phase1-gate.mjs`: mechanical wave-gate checks.
- Per-slice string catalogues `src/i18n/en-a.js` to `en-f.js`, spread into `en.js`.
